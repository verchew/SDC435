Repo for uploading python application files for NoSQL databases

### mongodb_crud.py
A python application that used PyMongo to perform CRUD on a MongoDB database ('Amazon') and collection ('ReviewData'). It allows users to add, query with filters, update, and delete customer review records.

### cassandra.Crud.py
A Python application using the cassandra-driver library to perform CRUD operations on an Apache Cassandra database. It creates a keyspace and tables, imports data from a JSON dataset, allow execution of CQL SELECT statements, modififes schema columns, and queries review statistics.
